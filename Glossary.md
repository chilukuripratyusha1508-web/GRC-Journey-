Asset: A thing which has some value. For example, if you buy gold every month it is an asset for you. In term of software and cybersecurity here we refer laptops as an asset.
Threat: Something that can cause damage. For example, an angry employee who can steal data and use this data in dangerous ways.
Vulnerability(loop hole an hacker can use to exploit threat): A Weakness that a threat can use. For example, if existing employee is a tester he should get access to view testing related documents if he gets access to everything there is a chance that he can misuse this information.
Risk: The chance of something bad happens. Eg: A hacker(threat) can guess weak password(vulnerability)and steals the data base (Asset).
Control: A safeguard that reduces risk. Eg: MFA , firewalls
Policy: It is a written rule which management says it should be done. Eg: Ever asset should be checked monthly and should be done patch.
Confidentiality: Only authorized people can see data. Encryption should be done to achieve highest confidentiality. 
Integrity: Data should be as is no modification or no changes should be done. hashing should be done.to achieve integrity. Eg: 3 idiots speech
Availability: System and data are accessible when needed.
Compliance: Following required laws, standards and rules.
Framework: A readymade structure of best practices. Eg: NIST
Audit: An independent check, using evidence, of whether controls exist and work. It can be internal or external.
Risk Assessment: Identify assets, threats and vulnerabilities, rate likelihood and impact, rank the risks and recommend what to do
Residual Risk: The risk which is left over after all controls are applied. It never comes to Zero.
Inherent Risk: The risk that exist before we applied controls.
Incident: An event that could negatively impact the system or server.
